# ResearchRadar：AI 期刊新文章推薦系統

ResearchRadar 會追蹤指定期刊最新線上發表的文章，用 AI（Claude）依你的研究興趣評分與推薦，並產生繁體中文的論文解析。結果輸出成用瀏覽器閱讀的 HTML 報告，以及 Excel 可以直接打開的 CSV 檔。

規格見 [SPEC.md](SPEC.md)。

## 安裝

需要：

1. **Python 3.11 以上**，只用標準函式庫，不需要另外安裝套件。
2. **Claude Code**，並且已經登入。AI 分析透過 `claude -p` 執行，使用登入帳號的訂閱額度。

## 使用方式

在 `ResearchRadar` 資料夾裡開終端機執行：

```
python radar.py                         # 跳出選單，選擇要跑的設定檔
python radar.py --profile steam-ai      # 直接跑某一組設定檔
python radar.py --all                   # 所有設定檔都跑
python radar.py --days 30               # 往回抓 30 天（可搭配上面任一種）
python radar.py --group SSCI            # 只跑某一類期刊
python radar.py --rescore steam-ai      # 設定檔改過後重新評分（論文解析不重做）
```

- **選擇設定檔**：不帶參數時會出現編號選單，例如「1. agent-sim　2. affective-ai　3. steam-ai」。輸入數字選一組，輸入「1,3」可以選多組。
- **只處理選到的設定檔**：AI 評分、CSV、HTML 報告都只針對選到的設定檔。沒被選到的設定檔，下次被選到時會自動補評之前累積的文章。
- 第一次執行預設往回抓 30 天，之後每次預設檢查最近 14 天，處理過的文章（依 DOI 判斷）會自動跳過。
- `--profile`、`--group`、`--rescore` 都可以重複指定，例如 `--profile steam-ai --profile agent-sim`。
- 之後的每日排程會固定帶 `--profile` 或 `--all`，不會停在選單。
- 加 `--no-open` 可以讓程式跑完不自動打開報告。
- AI 分析失敗的文章（例如額度用完），下次執行會自動重試。
- 執行前請先關掉 Excel 裡開著的 CSV，不然程式無法寫入。

## 輸出

結果在 `output/` 資料夾，每次執行只產生選到的設定檔的輸出。

### HTML 閱讀報告

日常閱讀用這份。檔名加上日期，例如 `output/2026-11-11_steam-ai.html`，每次執行產生一份新的，保留歷史紀錄。跑完會自動用瀏覽器打開。

- **收錄範圍**：這次抓取區間內的所有文章；這次新抓到的文章會標示「新」。
- **排序**：依星等由高到低，同星等依發表日期由新到舊。
- **3 星以上**的文章完整顯示：標題 → 星等 → 一句話重點 → 推薦理由 → 作者、日期、方法類別、連結 → 研究目的、研究方法、主要結果、研究亮點、結論。
- **1–2 星**的文章只顯示標題、星等、一句話重點和推薦理由，點開才看得到完整解析。
- 每篇都附英文原文摘要，預設收起來，點開才顯示，方便對照 AI 的解析。
- 星等用 ★★★☆☆ 符號，依星等上不同顏色。
- 更正、撤稿等非研究文章放在報告最下方，只列標題和連結。

### CSV 總表

資料保存與 Excel 篩選用。**每組興趣設定檔一個累積總表**，例如 `output/steam-ai.csv`。每次執行會更新整份表，依發表日期由新到舊排列。

| 欄位 | 說明 |
|---|---|
| 星等 | 1–5，用數字，方便在 Excel 排序；規則見下方 |
| 推薦理由 | 這篇文章跟該研究興趣的關聯 |
| 一句話重點 | 一句話說明文章做了什麼、發現什麼 |
| 標題、作者、發表日期、期刊、DOI、連結 | 文章基本資料 |
| 方法類別 | 量化研究、質性研究、混合方法、系統性回顧／後設分析、設計本位研究、系統開發與評估；都不適合時由 AI 描述 |
| 研究目的、研究方法、主要結果、研究亮點、結論 | AI 以「論文理解專家」角色解析的結果 |
| 備註 | 「無摘要，僅依標題」「非研究文章」「AI 分析失敗，下次執行會重試」 |

所有處理過的文章與 AI 結果都存在 `data/articles.json`，CSV 是從這個檔案產生的。

## 星等規則

AI 依興趣設定檔的研究描述與關鍵字，判斷每篇文章的關聯程度：

| 星等 | 意思 |
|---|---|
| 5 | 必讀，跟研究直接相關 |
| 4 | 值得細讀 |
| 3 | 值得看摘要 |
| 2 | 有點相關，看標題就好 |
| 1 | 無關 |

- 關鍵字只給 AI 參考，**不做硬過濾**：每篇文章都會評分，AI 依研究內容的實質關聯判斷，不只看字面。
- AI 被要求保守給分，大多數文章對特定研究興趣只會是 1–2 顆星。
- 更正啟事、撤稿聲明等**非研究文章**會列在 CSV，但不解析也不評分。
- 抓不到摘要的文章只用標題解析和評分，解析內容會標示「（依標題推測）」。

## 新增興趣設定檔

在 `profiles/` 資料夾新增一個 `.toml` 檔，**檔名就是設定檔代號**（例如 `my-topic.toml` → `--profile my-topic`）。可以複製現有的檔案來改：

```toml
name = "設定檔名稱"

# 適用期刊分類（對應 journals.toml 的 tags）；空白 [] 表示套用所有期刊
groups = []

description = """
3–5 句的研究描述：你研究什麼、關注什麼、偏好哪類論文。
"""

keywords = ["keyword one", "keyword two"]
```

- 研究描述是 AI 評分最重要的依據，寫得越具體，推薦越準。
- 關鍵字建議用英文，因為文章是英文。
- 新增的設定檔下次執行時，會自動對已有的文章補評分。
- 修改既有設定檔後，用 `--rescore <代號>` 重新評分。

目前的設定檔：

| 代號 | 名稱 |
|---|---|
| `agent-sim` | 模擬學生的 LLM Agent |
| `affective-ai` | 情緒、推理、記憶的 AI 系統 |
| `steam-ai` | STEAM 與 AI 教育 |

## 新增期刊

### 期刊選擇準則

**新增的期刊以 JCR Q1–Q2 為準**，由使用者自行篩選後再加入，程式不記錄分區。

### 設定方式

在 `journals.toml` 複製一段 `[[journal]]`，修改內容：

```toml
[[journal]]
id = "eit"                                        # 期刊代號（英文，不能重複）
name = "Education and Information Technologies"   # 期刊全名
issn_print = "1360-2357"                          # 紙本 ISSN
issn_online = "1573-7608"                         # 電子版 ISSN
tags = ["SSCI", "教育科技"]                        # 分類標籤，可以有多個
source = "springer"                               # 資料來源
springer_id = "10639"                             # Springer 期刊編號
```

- **標籤**：SSCI、SCI、Scopus 等收錄資訊沒有免費的查詢介面，請自行確認後填寫。執行時可以用 `--group` 只跑某一類期刊，興趣設定檔的 `groups` 也對應這些標籤。
- **Springer 期刊編號**：期刊網址 `link.springer.com/journal/<編號>` 裡的數字。
- **目前只支援 Springer 期刊**。資料來源是 Springer RSS（標題、日期、DOI、摘要、連結）加上 Crossref（作者）。其他出版社（Elsevier、Wiley、Taylor & Francis 等）的期刊需要另外寫資料來源，而且可能抓不到摘要。

## 設定

`settings.toml`：

| 設定 | 說明 |
|---|---|
| `model` | AI 模型，預設 `claude-sonnet-5-5`；想要判斷更細可改成 `claude-opus-5-5` |
| `workers` | 同時進行的 AI 分析數量，預設 4 |
| `timeout_seconds` | 單次 AI 呼叫的時間上限 |
| `claude_path` | claude 執行檔位置，通常不用填 |

## 檔案結構

```
ResearchRadar/
  radar.py          主程式
  settings.toml     模型等設定
  journals.toml     期刊清單
  profiles/         興趣設定檔，一組一個檔案
  output/           HTML 閱讀報告（每次一份，檔名含日期）與 CSV 總表（一組設定檔一個）
  data/             所有處理過的文章與 AI 結果（articles.json）
  SPEC.md           規格書
  README.md         本文件
```
